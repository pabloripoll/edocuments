# Programming

- **program**: is a sequence of instructions written in a programming language.
- **process**: is simply an instance of a program tah is being executed.
- **thread**: is a unit of execution within a process.

Los fundamentos de programación son los conceptos lógicos y estructuras universales que permiten crear software. Dominar estas bases teóricas te otorgará la habilidad de resolver problemas y programar en cualquier lenguaje (como Python, JavaScript o Java).

## Conceptos Clave

- Algoritmo: Conjunto ordenado y finito de pasos lógicos que permiten resolver un problema o realizar una tarea.

- Variables y Tipos de Datos: Las variables son contenedores para almacenar datos. Los tipos definen qué clase de dato se guarda (ej. números enteros, textos o booleanos).

- Estructuras de Control: Permiten dirigir el flujo de ejecución de un programa. Incluyen condicionales (como if/else) para tomar decisiones y bucles (como for o while) para repetir acciones.

- Funciones: Bloques de código reutilizables diseñados para realizar una tarea específica. Ayudan a mantener el código organizado y limpio.

## Paradigmas de Programación

Son los diferentes enfoques o estilos para estructurar un programa. Los más destacados son:

- Programación Imperativa: Se basa en dar al ordenador una secuencia paso a paso de cómo realizar una tarea.

- Programación Orientada a Objetos (POO): Organiza el código en "objetos" que contienen datos y comportamientos. Se apoya en cuatro pilares: Abstracción, Encapsulamiento, Herencia y Polimorfismo.

- Programación Funcional: Trata las operaciones matemáticas como cálculo de funciones puras, evitando modificar los datos originales.
