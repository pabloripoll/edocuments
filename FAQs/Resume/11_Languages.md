# Resume - Languages

Compiled Languages: Go, C++, C
Source Code -> Is has to be compiled into Machine Code -> CPU

Bytecode Languages: Java, C#
Source Code -> Is has to be compiled into Bytecode -> Virtual Machine / JET *(Just in Time - Bytecode into Machine Code)* ->  CPU

Interpreted Languages: Python, PHP, Ruby, Javascript
Source Code -> Interpreter -> CPU
