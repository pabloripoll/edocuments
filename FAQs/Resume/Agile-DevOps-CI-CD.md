## Scrum
Sprints *(common of two weeks)*

Scrum Board
| TO DO      | BUILD     |  TEST  | DONE   |
| :--------: | :-------: | :----: | :----: |
| BackLog 1  |   built   | tested |  Done  |
| BackLog 1  |   built   |        |        |
| BackLog 1  |           |        |        |

Meetings:
- Sprint Review
- Sprint Retrospective

## Kanban
Continuos process

Kanban board
| TO DO      | TEST      |  DONE  |
| :--------: | :-------: | :----: |
| BackLog 1  |  tested   |  done  |
| BackLog 1  |           |        |
| BackLog 1  |           |        |

- Daily Stand-up meetings

## Terraform
[https://developer.hashicorp.com/terraform/intro](https://developer.hashicorp.com/terraform/intro)

Terraform is an infrastructure-as-code software tool *(IaC)* written in GO which main target is to do provisioning.


used to define and provide data center infrastructure by a declarative configuration language known as HCL *(HashiCorp Configuration Language)*, or optionally by JSON.

Terraform creates and manages resources on cloud platforms and other services through their application programming interfaces (APIs). Providers enable Terraform to work with virtually any platform or service with an accessible API.
