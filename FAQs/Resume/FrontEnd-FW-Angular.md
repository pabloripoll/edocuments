Directivas: https://angular.io/guide/structural-directives
- Añaden comportamiento a un elemento del DOM existente

Componente:
- Controla una parte de la pantalla, llamada vista.
- Los componentes son bloques de construcción de interfaz de usuario.
- Son subconjuntos de directivas, pero a diferencia de las directivas, siempre poseen una plantilla HTML.

Angular CLI:
- Interfaz de linea de comando para montar y construir aplicaciones de Angular

Diferencia entre Contructor vs ngOnInit
- Las clases de typescript tienen un método predeterminado llamado constructor que normalmente se utilizaa con fines de inicialización y siempre se ejecuta primero
- ngOnInit es un método espécifico de Angular y se usa para definir el binding en el cual se debe implementar la interfase onInit

Directivas Estructurares: https://angular.io/guide/structural-directives
- Permiten añadir, manipular o eliminar elementos del DOM, como ngIf or ngFor
- NgIf: Inserta o elimina elementos del DOM basados en una condición.

Interpolación:
- Sintaxis especial de angular que permite hacer el binding de una propiedad, es una alternativa al property-binding y está representado por doble llaves

Binding: https://angular.io/guide/binding-overview
En una plantilla Angular, un binding crea una conexión en vivo entre una parte de la UI creada a partir de una plantilla (un elemento DOM, directiva o componente) y el modelo (la instancia del componente al que pertenece la plantilla). Esta conexión puede utilizarse para sincronizar la vista con el modelo, para notificar al modelo cuando se produce un evento o una acción del usuario en la vista, o para ambas cosas. El algoritmo de detección de cambios de Angular se encarga de mantener sincronizadas la vista y el modelo.

Algunos ejemplos de vinculación son

- interpolaciones de texto
- vinculación de propiedades
- vinculación de eventos
- vinculación bidireccional

Las vinculaciones siempre tienen dos partes: un destino que recibirá el valor vinculado y una expresión de modelo que produce un valor a partir del modelo.
