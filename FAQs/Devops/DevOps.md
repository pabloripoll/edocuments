# DevOps

DevOps is a set of practices, tools, and a cultural philosophy that automate and integrate the processes between software development and IT teams. It emphasizes team empowerment, cross-team communication and collaboration, and technology automation.

## Objetives for DEV

- Aplication Performance: Decrease latency by APM tools

- End User Analytics: Monitor End User latency and check device perfomace

- Quality Code: Ensure deployments don't degrade performance

- Code Level Errors: Lower MTTR by finding error root causes

## Objetives for OPS

- Application Availability: Make sure Uptime and SLAs are in order

- Application Performance: Solve problems by correlating infrastructure and application metrics

- End user Complains: End problems before end user complains

- Performance Analitycs: Use automatically generated baselines to focus troubleshouting
