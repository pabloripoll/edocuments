# eTechnicae - AbcElectronics

https://quickref.me/

This is a library for documenting different subjects on eletronics, both hardware and software enviroments, like foundations, fundamentals and basics of useful information to start up a project.

`The Foundation of ...` is what constitutes the genesis of what you are talking about. A book titled "Foundations of Machine Learning" would cover the ideas that motivated the creation of this field of computer sciences: the math and the theories. \
`The Fundamentals of...` are the parts of the whole that cannot be detached or else it would become a different thing. A book named "Fundamentals of Machine Learning" would cover the elemental parts to build a Machine that Learns: algorithms. \
`The Basics of ...` of Machine learning would be an introduction to the topic. A book named "Machine Learning Basics" would cover examples of basic systems and how to program/code one.
