
## Normal Render Application
Browser requests to URL and server processes the request to respond with a whole new HTML *(js, css, images)*

## CSR - Client Side Rendering
Client Side Rendering is the technic on which the browser requests to URL and server processes the request and just response the information required for the client to build on client the application.
